# Contributing to TruckTracker

Thank you for your interest in contributing to TruckTracker!

## Getting Started

1. Fork the repository and clone it locally.
2. Ensure you have Node.js 22+ installed.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run tests and type checking:
   ```bash
   npm test
   npm run build --workspace=web
   npm run build --workspace=server
   ```

## Development Workflow

- Create a feature branch (`git checkout -b feature/your-feature-name`).
- Follow project coding standards and ensure TypeScript types compile cleanly.
- Commit your changes with clear, semantic commit messages (e.g., `feat: ...`, `fix: ...`, `docs: ...`).
- Open a Pull Request against the `main` branch with a description of the changes.

## Code Standards

- Maintain documentation integrity and preserve code comments.
- Adhere to the Contributor Code of Conduct.
